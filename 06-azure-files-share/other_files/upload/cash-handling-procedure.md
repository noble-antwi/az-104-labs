# Cash handling procedure

Owner: Branch Operations
Applies to: tellers and the branch manager

1. Count the opening float with a second staff member and both sign the float sheet.
2. Never leave a cash drawer unlocked when away from the counter.
3. Deposits above GHS 50,000 need the branch manager's sign-off.
4. Count the drawer at close, record any difference over GHS 10, and report it the same day.
5. The vault is opened only by two key holders together.
